## Повседневное использование и следующий вход

Личный bootstrap, регистрация проектов и место/расписание backup выполняются только
по явному запросу; публикация движка их не запускает. Обычная работа разрешена без request.

Архитектурные решения MCP подтверждены в комментариях к [плану](docs/MCP-PLAN.html):
общий API, пользовательское подключение, штатный MCP + инструкция без управления сессиями.
После удаления импорта каталог содержит 31 инструмент. Реализация MCP этой работой не начата.
Он не означает автоматического управления сессиями, flow или запуска агентов.

## Сохраняемые ограничения

Только M1, без файловой копии DB lifecycle, прежнего паспорта проектов,
универсального operations/recovery engine и заранее созданных будущих таблиц.
Сеть/внешние записи отдельно разрешаются; БД и пользовательский home не коммитятся в Git движка.
Политика тестирования — [TESTING](docs/TESTING.md); бюджеты не меняются ради green.
