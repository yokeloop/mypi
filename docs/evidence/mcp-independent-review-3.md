## Остальная корректность

- Входные схемы strict, включая вложенные scope/source/artifacts; неизвестные поля не удаляются молча.
- CLI/MCP используют общий typed API; DB-only ветка не открывает workspace.
- Lookup учитывает canonical path, границы компонентов, deepest match и ambiguity.
- Partial сохраняет recovery-поля; автоматического retry нет.
- Очередь ожидает async backup, проверяет отмену перед исполнением; stop запрещает ожидающую работу и дожидается активной.
- Scope не представлен как ACL; внешние файловые аргументы и административные полномочия описаны честно.
